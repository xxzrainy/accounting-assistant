# Accounting Assistant

Google Apps Script 記帳小幫手。

## 開發環境

- [clasp](https://github.com/nicholaschiang/clasp) — 本地開發與部署 GAS

## 使用方式

```bash
# 安裝 clasp
npm install -g @nicholaschiang/clasp

# 登入 Google 帳號
clasp login

# 推送程式碼到 GAS
clasp push

# 從 GAS 拉取程式碼
clasp pull

# 開啟 Apps Script 編輯器
clasp open
```

## 專案結構

```
src/       # GAS 原始碼目錄
.clasp.json # clasp 設定檔
```
